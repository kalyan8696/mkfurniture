# M K FURNITURE — Static Website

This is a small static site scaffold for the M K FURNITURE wood-furniture site.

Files:

- `index.html` — Home with welcome animation and social links
- `projects.html` — Gallery of project photos
- `about.html` — About / details (Hindi + English)
- `contact.html` — Contact page with form and WhatsApp link
- `css/style.css` — Styles and color palette
- `js/main.js` — Small JS to dismiss welcome overlay

To view locally open `index.html` in your browser.
